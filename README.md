# Ayman Fathima Portfolio — Static HTML / CSS / JS

Pure static website (**zero Node.js, zero PHP, zero build tools, zero `.env` files**). Ready to deploy directly to **GitHub Pages** or **Vercel**.

## Files
- `index.html` — Complete portfolio page
- `assets/css/style.css` — Standalone CSS
- `assets/js/main.js` — Scroll progress bar, reveal animations, magnetic hover, portrait parallax, mobile menu, email copy, and project modal
- `assets/images/` — Portrait, 4 live project screenshots, and `favicon.svg`
- `assets/files/Ayman_Fathima_CV.pdf` — Downloadable resume PDF

## Deploy to GitHub Pages
1. Create a new GitHub repository and upload the contents of `html-project/` (so `index.html` is at the repository root).
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, pick `main` / `/ (root)`, and click **Save**.

## Deploy to Vercel
1. Upload the `html-project/` contents to a GitHub repo (or drag-and-drop the folder in Vercel).
2. Framework Preset: **Other** (no build command needed, Output Directory: `.`).
3. Click **Deploy**.
